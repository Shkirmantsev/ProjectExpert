# Licensing interface reference

Implements the
[`license-governance`](../../../openspec/specs/2026-10-04-license-governance/spec.md)
spec.

## License policy

`pi_platform.core.licensing.policy.LicensePolicy.evaluate(dependency)`
returns `(decision, reason)` where `decision` is one of
`"allow"`, `"review"`, `"deny"`. The default lists match the
spec:

- `allow`: `Apache-2.0`, `MIT`, `BSD-2-Clause`, `BSD-3-Clause`, `ISC`
- `review`: `MPL-2.0`, `EPL-2.0`, `LGPL-2.1-only`, `LGPL-3.0-only`
- `denyPatterns`: `*-NC-*`, `research-only`, `non-commercial`,
  `source-available-restricted`

A missing SPDX identifier is always a `deny`.

`PolicyConfig.from_dict(payload)` reads the documented allow /
review / denyPatterns keys from
`project-knowledge/project-context.yaml`.

## License gate

`pi_platform.core.licensing.gate.LicenseGate.run(dependencies)`
returns `(passed, findings)`. The gate ignores entries with
`scope == "system"` so the stub Python standard-library inventory
shipped by `init-project` does not block a fresh target
repository. Dependencies on the `review` list pass only when a
matching `"<name>@<version>"` entry is present in the
`review_acceptance` map.

The CI license gate is wired as `make license-gate TARGET=<repo>`.

## Dependency / model-license inventories

`DependencyInventory` and `ModelLicenseInventory` load and save
the JSON artefacts:

- `distribution/licenses/dependency-inventory.json`
- `distribution/licenses/model-licenses.json`

The stub inventory generated by `init-project` lists two
`scope: "system"` entries (Python + Python stdlib) so the gate
passes against a freshly initialised target.

## SBOM and NOTICE emitter

- `emit_spdx_sbom(dependencies, ..., output_root)` writes an
  SPDX-2.3-compatible JSON document under
  `distribution/sbom/PROJECT-INTELLIGENCE.sbom.json`.
- `emit_notice_file(dependencies, ..., output_root)` writes a
  plain-text NOTICE listing every `allow`-resolved dependency
  as `<name>:<version> - SPDX:<license-id> - <source>`.

## CI license gate target

`make license-gate TARGET=<repo>` invokes
`python -m pi_platform.cli license-gate --target <repo>` and
exits non-zero when the gate fails. The Make target is the
Phase 1 CI gate; later phases wire the inventory generator.

## Plugins, hooks and adapters

Plugin and hook license checking arrives in Phase 7 with the
central policy engine. The Phase 1 contract exposes the
`LicenseGate` and the dependency inventory so Phase 7 can
extend it without changing the public surface.
