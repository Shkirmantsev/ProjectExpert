# v0.8 Ingestion, Retrieval, and Local-Model Refinement Invariants

The v0.8 refinement (`improve-ingestion-retrieval-local-models`) preserves all 52 baseline §68 probes (`kb://invariants/v0.8`) and enforces the thirteen §39 refinement invariants:

1. **Git canonical truth** — durable project knowledge lives in Git; SQLite tables (`embeddings`, `document_revisions`, `ingestion_jobs`) and USearch indexes are derived runtime state.
2. **Runtime rebuildability** — deleting `.project-intelligence-cache/` or ANN index files never loses canonical knowledge; ANN rebuilds from `VectorRecordStorePort`.
3. **Branch awareness** — runtime queries, caches, and traces remain bound to `ProjectVersion`.
4. **Content-addressed reuse** — unchanged `retrieval_text_hash` and `ContextualizationCache` keys reuse prior records across branch switches.
5. **OpenSpec normativity** — `openspec/specs/` remains the normative contract; proposed vs accepted temporal boundaries are preserved.
6. **Source provenance** — `SourceAnchor`, `Citation`, `CandidateTrace`, and `SupportEvidence` preserve page, element, and duplicate-collapse provenance.
7. **License governance** — optional model/parser adapters obey the License Gate and pinned revision rules.
8. **Offline operation** — all Tier-1 and default Tier-3 workflows run with zero outbound network access.
9. **CPU fallback** — `HashingEmbeddingAdapter`, `Bm25LightRerankerAdapter`, `RerankWithFallback`, and `HostEmbeddingClient` guarantee CPU operation when GPU/accelerator or optional weights are absent.
10. **Single-container default** — the host accelerator (`pi_platform/host_accelerator/`) is strictly opt-in.
11. **MCP retrieval-first behavior** — `project.retrieve_context` surfaces `selection_state`, `support_relationships`, `conflicts`, and debug `retrieval_trace_id` without exposing raw database access.
12. **Control Plane authorization** — `InferencePolicy`, debug traces, and diagnostics panels (`ui.v0_8.*`) respect Policy Engine, Secret Provider redaction, and §59.16 declarative UI rules.
13. **Agent and vendor neutrality** — all contracts remain standard MCP + OKF + Agent Skills.
