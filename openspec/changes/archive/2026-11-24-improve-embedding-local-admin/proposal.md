# Improve embedding throughput and local administration

## Why

A forwarded local browser could be denied administrative access. The semantic pipeline rewrote ANN metadata and repeated work already validated during restore.

## What Changes

Use a Docker operator bootstrap for local browser administration, group ANN candidate mutations, skip restorative reinsertion, and provide wider windows to evidence-gated document endpoints. Add a synthetic throughput diagnostic, shorten primary Windows offline extraction paths and reuse successful bundled Java version probes.
