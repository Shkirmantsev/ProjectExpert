# Design

Use the local operator's Docker access to open a browser tab with a private container-scoped credential. The launcher obtains the credential through Docker exec, passes it in a URL fragment and the page removes the fragment before making HTTP calls. The credential is distinct from the optional API token and from operator approval keys. Direct native loopback retains automatic owner access. Managed wildcard listeners infer no authority from forwarding addresses.

Keep the candidate generation disposable. Group ANN changes and stable key allocations, and report an already validated restore directly. Increase the bounded work window only for the existing evidence-gated document dispatcher, with endpoint request limits and explicit projection spans. Route media through the primary binding. Keep numerical parity and combined performance gates for mixed devices.
