# Ponytail

Adapted from the downstream this project catalog skill.

1. Understand the requested outcome and trace affected callers before editing.
2. Reuse existing repository behavior, then the standard library, then native
   platform features, then installed dependencies before adding custom code.
3. Implement the smallest coherent change that meets the acceptance criteria.
   Omit speculative abstractions and dependencies; explain a material omission.
4. Fix the shared root cause when several callers exhibit the same defect.
5. Preserve input validation, data safety, accessibility, compatibility and
   explicit user requirements. Simplicity never excuses an incomplete task.
6. Run the smallest meaningful check and review the diff before completion.

Apply only when selected for this task. Project workflow, required evidence and
user communication take precedence; no persistent persona or output restriction.
