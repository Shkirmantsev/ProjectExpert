# Project exploration

1. Read only `AGENTS.md`, `.ai/wiki/INDEX.md`, and the immediate task target first.
2. Use `kb_search`/repository search to narrow modules, symbols, interfaces, and specs.
3. Use deterministic build/module/dependency metadata where available.
4. Retrieve selected Wiki sections; do not recursively load documentation trees.
5. Update `.ai/wiki/project/project-map.md` only with durable reviewed navigation facts.
6. Tag uncertainty and unresolved evidence explicitly.
