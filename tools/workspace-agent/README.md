# Native managed workspace helper

Build with Go 1.22+ (`go build .`); cross-build with `GOOS=windows GOARCH=amd64 go build .`.
Only the Go standard library is used. The application image must contain the Python importer.

All commands require `--repo ABSOLUTE_HOST_REPOSITORY --kit DEPLOYMENT_KIT`:

- `prepare`: verify local active Docker context and Linux engine; make host canonical directory; write nonsecret identity/config `workspace-agent.json` and Compose variables `workspace.env`. Does not create volumes or import. PI_IMAGE comes from environment or kit/deployment.env.
- `sync`: create named workspace/runtime volumes, perform a stable native scan, stream changed source bytes into the restricted importer, save accepted manifest/status. First import must succeed before application startup.
- `supervise`: exclusive per-kit lock, native change hints with 1.5s debounce, five-second reconciliation, capped connection retry backoff. Keep this process supervised by the normal launcher. `stop` writes this kit's stop request; `status` prints last sync/error metadata. OS advisory supervisor and operation locks release automatically on process death. No PID is killed.

Every Docker operation explicitly selects the prepared context. A changed active context refuses transfer. TCP/SSH Docker endpoints are refused. No privileged containers, daemon socket, host source mount, or network is used for transport. The importer mounts only its managed source volume. Backup separately mounts source read-only and the runtime volume; canonical knowledge is excluded from backups. Preparation checks image modules and verifies canonical host read/write identity under the configured application UID. Login registration is explicit launcher integration.

`.projectexpert-workspaceignore` supports blank lines, # comment lines, root-relative slash globs, basename globs matching any path component, and `folder/` prefixes. PI_WORKSPACE_EXCLUDE adds comma/newline-separated patterns. Spaces and Unicode are literal. Negation, `**`, backslash, `..`, colon and invalid glob syntax fail clearly. Built-in secret/VCS/canonical/runtime/build/deployment exclusions cannot be overridden. PI_WORKSPACE_MAX_FILE_BYTES is a positive byte count (default 1GiB); larger files are omitted before opening. Changing exclusions removes formerly managed files on the next trusted complete reconcile. Ignored content must never be required source input.

Scans retain bounded manifest metadata (200k files/20GiB total); hashes stream with constant buffers. Size and nanosecond modification timestamps reuse hashes; full hash verification happens after 300 seconds. Linux inotify hints cover existing directories; newly created subtrees and overflow are covered by periodic reconciliation. Windows ReadDirectoryChangesW requests recursive notifications. Native watcher failure falls back to polling. Same-stat content modifications are caught by event invalidation or periodic verification. No public speed claim is made. Native Windows execution and Docker engine integration require hardware acceptance tests; cross-compilation alone does not establish support. Windows ACLs have no POSIX UID/GID; the initial importer uses 1000:1000 there and requires canonical ownership smoke validation.

Protocol: streaming uncompressed tar, first regular member `manifest.json` (schema_version=1, generation, files mapping path to size/sha256, vcs), then changed regular file payloads only. The receiver verifies complete manifest, confinement, collisions, size/hash and unchanged receiver files before source mutation. Durable staged data and `importing.json` journal replay under `ProjectLock('commit')`; application refresh must fail closed while journal exists. `applied-generation.json` publishes last. Deletes affect only the prior accepted manifest. Recovery replays forward, rather than rolling back a partially applied source tree; readers must honor the commit fence. Sync transmits zero source payload bytes for unchanged generations, including a complete reconcile. The receiver manifest is read before every transfer; host manifests are recoverable hints.

Backup: `backup --repo PATH --kit PATH` exports coordinated snapshots to an outside-source private directory. The supervisor schedules after active generation changes and every 30 minutes. `restore --repo PATH --kit PATH --backup SNAPSHOT` requires the app/supervisor stopped, restores a new inactive runtime volume, selects it and preserves the old volume. Windows filesystem metadata durability needs native acceptance; Linux fsync behavior is tested separately.

Release compiler: Go 1.27.4, pinned archive SHA-256 in Containerfile. The host compiler used for local compatibility tests may be older; release CI builds and records actual Go build metadata. Standard library only, no downloaded Go modules. See distribution/licenses/workspace-agent.json.
